========================================================================
                      UPPSTRIVE AGENCY WEBSITE
========================================================================

Welcome to the UppStrive Website repository! UppStrive is a premier 
Digital Marketing & IT Services Agency delivering customized strategies in 
performance marketing, custom software development, cloud infrastructure, 
and AI solutions.

------------------------------------------------------------------------
1. BRAND IDENTITY
------------------------------------------------------------------------
* Primary Tagline: "Marketing that converts. Tech that scales."
* Closing Line:    "Let's grow together."
* Favicon:         Rebranded to the official UppStrive logo.

------------------------------------------------------------------------
2. DIRECTORY STRUCTURE
------------------------------------------------------------------------
* index.html      - Main SEO-optimized landing page structure and meta tags
* css/            - Stylesheets (styles.css, animations.css for sliders)
* js/             - Vanilla JavaScript (animations.js for modals and sliders)
* assets/         - Hydrating React bundle assets (home, footer, root, etc.)

------------------------------------------------------------------------
3. FEATURES & SECTIONS
------------------------------------------------------------------------
* Hero Section:      Introductory tagline, description, CTA buttons.
* Stats Section:     Performance growth metrics (Average ROI, Brands Scaled).
* Services Section:  Custom marketing and software cards (Performance 
                     Marketing, Web & Mobile, CRMs, AI & Cloud).
* Why Choose Us:     Key differentiators (Growth-focused, unified marketing 
                     & tech, result-oriented execution).
* Client Reviews:    Success testimonials (SEO audits, lead automation, CRMs).
* Contacts & Lead:   Interactive modal popup triggered by CTA buttons.

------------------------------------------------------------------------
4. HOW TO RUN THE WEBSITE LOCALLY
------------------------------------------------------------------------
To run the website locally, use any static web server in the directory.
For example, using Python:

    python -m http.server 8000

Then open your browser and navigate to: http://localhost:8000/
